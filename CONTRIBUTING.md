# Contributing

Contributions must be original or appropriately licensed and must not include
Icom firmware, extracted firmware content, ready-to-flash images, proprietary
artwork, credentials, recordings, station logs, or personal data.

Before opening a pull request:

1. Keep changes scoped to one issue and state the target official firmware
   version, if relevant.
2. Run the applicable tests and describe the result using the
   [test checklist](docs/TEST_CHECKLIST.md); desktop tests mark hardware fields
   inapplicable.
3. Document new reverse-engineering claims with reproducible evidence rather
   than vendor-derived source listings.
4. Do not enable RF transmission, bypass safety checks, or change frequency,
   power, PTT, or update behavior without an approved test plan.

By contributing, you confirm you have the right to submit the material under
the repository's license. Maintainers may reject material that creates legal,
safety, or licensing risk.
